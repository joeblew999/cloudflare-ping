## cloudflare-ping

- This project uses [cloudflare-ping](https://cloudflare-ping.gedw99.workers.dev): probes from around the world, run
  from Cloudflare's data centres. Starting a run or a test spends tests; check `limits` first.
- Its MCP server is `https://cloudflare-ping.gedw99.workers.dev/mcp` (it signs in through the browser); its CLI is
  `cloudflare-ping` (`cloudflare-ping help`). The `cloudflare-ping` skill says when to use which.
